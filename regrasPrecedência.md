## Ordem Precedência

1. Operadores Unários/Aritméticos de alta prioridade (!, - unário)

2. Aritmética (*, /, depois +, -)

3. Relacionais (<, <=, >, >=)

4. Igualdade (==, !=)

5. E lógico (&&)

6. OU lógico (||)

--> Em C, 0 representa FALSO e qualquer valor diferente de zero representa VERDADEIRO (o resultado de operações lógicas é sempre 1 para verdadeiro e 0 para falso).


--> Um número em C é considerado verdadeiro(1). => OBS: (Lembrar disso quando tiver operações ternárias)
